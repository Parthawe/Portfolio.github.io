Enigma

Interactive light sculpture embodying a real functioning deep learning network

Year2023
RoleCreator
Contents Concept Technology Exhibition

Overview

200 Neurons of Light

Enigma is an interactive light sculpture that intricately embodies a real functioning deep learning network, using 200 unique illuminated neurons to artistically elucidate the complexity of neural networks, inviting audiences to explore the convergence of art and science in a captivating visual experience.

The genesis of this project drew inspiration from the ‘Abacus’ project undertaken at panGenerator Studio. While ‘the Abacus’ focused on recognizing digits, Enigma operates on a similar concept but with alphabetic characters instead of digits.

01 — Concept

Illuminated Neural Architecture

200 individually addressable LED neurons arranged in a network topology that mirrors a real neural network architecture. Each neuron lights up as data flows through the network during inference.

02 — Technology

From Model to Light

Built with a trained character recognition model, Arduino controllers, and custom LED drivers. The sculpture processes handwritten alphabetic input in real-time, with each layer of the network visualized through light.

03 — Exhibition

ITP Winter Show 2023

Exhibited at ITP Winter Show 2023. Audiences could write characters on a tablet, watching the neural network process their input through 200 physical light nodes.
