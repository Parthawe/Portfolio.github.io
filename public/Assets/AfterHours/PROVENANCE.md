# After Hours illustration sources

The workshop and character atlases were generated for this fictional interactive illustration using the built-in OpenAI image-generation tool on October 25, 2026. They are AI-assisted artwork. They are not a specific painter's work, film frames, commissioned hand painting or an imported Floor796 asset.

The original PNGs are retained in the cloud workspace under `/workspace/generated_images/`. Their WebP versions are encoded without resizing; lossy compression changes pixel values. Source registration is measured from the PNG alpha components. Runtime code samples those frames and supplies motion, contact anchors, ground placement, lighting treatment and navigation. No third-party art account, purchase or API integration was added.
