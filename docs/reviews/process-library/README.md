# Project references and process

The public portfolio now has `/process` and `/process/{slug}` reading views. Every case-study and practice-entry header links to its archive, with a return link to the case study. The Work page links to the full index.

The public projection is static portfolio content. It does not fetch Taste Index account records or private originals, and does not change the library's audience. The registry covers all 50 currently routable projects. Twenty-one projects have 67 curated public artifacts, including six Mentra source decisions. Other projects show their existing source limitations. Request-access projects expose no process imagery.

Public artifacts were selected from files already used in public case studies. The provenance JSON records their source file/line, source chapter, caption and evidence limits. Curation excludes an unrelated food-ordering screen previously captioned as VJ parking, an Office of Diversity research-wall photograph whose relationship is unverified, generated project covers, private Figma captures, and NDA source material.

Sculpture's original process board labels failed ideas. Its individual rejection reasons remain unknown. Mentra's original comparison documents bottom drawer, persistent dock and card switcher alternatives; the comparison is qualitative. Other source artifacts do not establish a rejection history. Questions under New directions to explore are newly authored proposals, not historical decisions.

Search and stage filters narrow project material. Artifact inspectors preserve query selection, allow direct links, use a native modal dialog, lock background scroll, and restore focus on close. Sources and full public images remain accessible. Missing previews retain a text fallback and a source route. There is no new canvas, animation loop, external image request, or runtime dependency.

Validation includes the production build, route checks, design audit, process-library source/access checks, and caption/source-protection checks. Browser review covers desktop light/dark, mobile 390px, search/empty recovery, stage filtering, inspector/Escape/focus restoration, source navigation, protected previews, and thin archives. Existing caption review limitations remain unchanged.
