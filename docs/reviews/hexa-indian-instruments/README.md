# Hexa-18 instrument sections

The creator clarified the installation’s layout: flute inputs at the top, tanpura inputs on the sides, tabla inputs inside. The preview now identifies those three Indian instruments and offers a section selector. Each section changes the illustrative browser sound: a sustained sine tone for flute, a decaying plucked string for tanpura, and a short falling-pitch percussive tone for tabla. These are synthesized approximations, not recordings or recovered instrument patches.

All 18 demo inputs remain available in a shared bank. The interface does not invent how the 18 sensors are divided among sections. Demo note numbers, tuning and physical sensor wiring remain explicitly unreconstructed.

The production build passed. The extended Jugalbandi additions check passed six profiles (Chromium desktop/mobile and WebKit mobile, both themes), covering all 18 channels, three section selectors, corresponding oscillator/buffer sound starts, keyboard, velocity, reset, viewport fit and eight rainstick mounts. No page errors. Screenshots and the report accompany this local change. No deployment.
