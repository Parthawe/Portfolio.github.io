# Cold Experiment Product Context

## Register
brand

## Product Purpose
This portfolio is a recruiter and collaborator interface for Parth Pawar, a design engineer working across AI wearables, fintech, civic systems, creative technology, installation, and brand systems. It should make the strongest proof easy to find without flattening the experimental range that makes the work distinctive.

## Primary Audiences
- Hiring managers and design leaders scanning for product judgment, systems thinking, and shipped work.
- Founders and collaborators checking whether Parth can own ambiguous 0 to 1 product work.
- Creative technology peers looking for range across code, hardware, fabrication, and interaction.

## Strategic Principles
- Start with proof. The first few screens should answer what Parth does, where the strongest work is, and why the range is credible.
- Keep private work private. Public pages can show a quick glimpse, but deeper NDA material must not ship in the static build.
- Treat navigation as an operating system. Home, work modes, categories, case studies, agent, hand controls, and Figma chrome should cooperate instead of competing for the same screen space.
- Make scanning easy. Every route should support quick reading, keyboard use, mobile use, and direct GitHub Pages refresh.
- Use the Figma/ruler language as subtle interaction chrome, not decorative clutter.

## Anti-References
- Do not clone Sanvithi. Only the idea of a short orientation loader is relevant.
- Avoid generic portfolio claims such as "seamless", "intuitive", "innovative", and "transformative" unless backed by concrete project evidence.
- Do not use lock icons or black-box NDA cards for request-access work.
- Do not let bottom controls cover project content on mobile.
