Shuffle

Interactive installation proposing a strategy simulation of student life at ITP

Year2024
RoleCreator
Contents Concept Process Exhibition
Shuffle — interactive tabletop installation with LED matrix and physical tokens

Overview

A strategy simulation tool

Shuffle is an interactive installation which proposes a contemporary interpretation of students’ lives: a strategy simulation tool inspired by G80, aimed at an equitable distribution of your time as a student on an ITP scale.

01 — Concept

Physical Redistribution of Time

The installation invites participants to physically redistribute their time across different aspects of student life at ITP. Each token represents a unit of time, and the LED matrix responds in real-time to placement decisions.

02 — Process

Hardware & Fabrication

Built with Arduino, addressable LEDs, and custom PCB. The physical interface uses weight sensors to detect token placement on a grid surface.

Controller Arduino
Display Addressable LEDs
Electronics Custom PCB
Input Weight Sensors

03 — Exhibition

ITP Winter Show 2023

Exhibited at ITP Winter Show 2023. Visitors engaged with the installation, sparking conversations about work-life balance in graduate school.
